SMART LIBRARY MANAGEMENT SYSTEM - DESIGN UPDATE

This project recreates the design direction of the HTML file you shared: a polished single-page library website with a navy-and-teal theme, hero section, facilities cards, about/rules, books table, and registration form.

Files:
- index.html: complete website in one file (CSS and JavaScript included)
- assets/: reserved for images if you choose to add any

How to use:
1. Download and extract the ZIP.
2. Open index.html in a browser to preview.
3. For GitHub Pages, upload index.html to the repository root and commit.
4. Make sure index.html is in the root of the selected publishing branch/folder.

Note: This is a front-end student demo. The registration form validates input and shows a confirmation, but does not save information to a database or send it to a server.
